# 示例
问题：BMW有哪些车型？
Cypher：MATCH (b:Brand {englishName: 'BMW'})-[:HAS_MODEL]->(m:CarModel) RETURN m.name AS modelName, m.fuelType AS fuelType, m.vehicleType AS vehicleType

问题：宝马3系有哪些版本？
Cypher：MATCH (b:Brand {name: '宝马'})-[:HAS_MODEL]->(m:CarModel {name: '3系'})-[:HAS_VERSION]->(v:CarVersion) RETURN v.name AS versionName, v.guidePrice AS guidePrice, v.status AS status

问题：哪些车在2025年还在售？
Cypher：MATCH (v:CarVersion {status: '在售', modelYear: 2025}) RETURN v.name AS versionName, v.guidePrice AS guidePrice

问题：宝马3系330i用了哪些配件？
Cypher：MATCH (v:CarVersion {infoId: 'CI_006'})-[:USES_PART]->(p:Part) RETURN p.name AS partName, p.category AS category, p.price AS price

问题：哪些车是纯电动的？
Cypher：MATCH (v:CarVersion)-[:HAS_ENERGY_TYPE]->(e:EnergyType {name: '纯电动'}) RETURN v.name AS versionName

问题：哪些车和Model 3长续航版使用了相同的轮胎？
Cypher：MATCH (model3:CarVersion {infoId: 'CI_001'})-[:USES_PART]->(p:Part)<-[:USES_PART]-(other:CarVersion) WHERE other <> model3 RETURN other.name AS versionName, p.name AS sharedPart
